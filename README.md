# L&D Playbook Skill — Flow & Recovery Guide

Visual reference for designers and stakeholders using the Breeze University L&D Playbook Skill.

- Shows the full flow (ALIGN → DESIGN → BUILD → LAUNCH → 05-DELIVERY)
- Names the signals that the skill is working properly at each phase
- Lists common drifts and how to redirect the skill by pointing it back to the playbook
- Includes an escalation path for repeat drifts

View: open `index.html` in a browser.
